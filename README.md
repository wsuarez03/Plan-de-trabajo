# Plan Trabajo

Una aplicación web para planificar recursos de personal utilizando un calendario interactivo.

## Características

- Gestión de trabajadores: Agregar y eliminar trabajadores.
- Gestión de proyectos: Agregar proyectos.
- Asignación de trabajadores a proyectos en fechas específicas.
- Prevención de conflictos: No permite asignar el mismo trabajador a dos proyectos en la misma fecha.
- Vista de calendario: Muestra las asignaciones en un calendario.
- Lista de personal disponible: Muestra los trabajadores disponibles en una fecha seleccionada.

## Tecnologías

- React
- TypeScript
- Vite
- FullCalendar
- date-fns

## Instalación

1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.

## Uso

1. Ejecuta `npm run dev` para iniciar el servidor de desarrollo.
2. Abre el navegador en `http://localhost:5173`.
3. Agrega trabajadores y proyectos.
4. Selecciona una fecha y asigna trabajadores a proyectos.
5. Haz clic en el calendario para seleccionar fechas.

## Construcción

Ejecuta `npm run build` para construir la aplicación para producción.
